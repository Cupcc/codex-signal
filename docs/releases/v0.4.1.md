# Codex Signal 0.4.1 · Build 5

语音提醒空闲时立即播放，移除三秒合并等待。

## 更新内容

- 审批、提问、失败和结束分别播放对应的内置中文音频。播放期间到达的提醒按顺序播放，不再合并多会话语音。
- 同一会话状态变化时移除过期的待播提醒；取消当前提醒后继续播放下一条。
- 移除两段多会话汇总音频。保留静音、勿扰时段、锁屏暂停和历史事件不补播策略。

## 下载和升级

需要 macOS 14+。`universal.dmg` 和 `universal.zip` 均包含 Apple Silicon 与 Intel 架构，任选一个下载。下载包可用随附的 `SHA256SUMS.txt` 校验。

0.3.0 及更新版本可在设置或菜单栏右键菜单检查更新，下载完成后点击“重启并更新”。手动升级时，退出旧版，再将新版 `CodexSignal.app` 拖入“应用程序”并替换；已有设置和提醒保存在本地数据目录。

首次安装见 [安装与接入说明](https://github.com/Cupcc/codex-signal/tree/v0.4.1#安装)。事件接入需要 Python 3；应用包包含桥接脚本。移动应用或更换 Python 后，需要重新生成 Hooks 配置。

## 当前边界

- 此版本使用 ad-hoc 签名，尚未通过 Apple 公证。首次打开若被 macOS 阻止，按 [安装说明](https://github.com/Cupcc/codex-signal/tree/v0.4.1#安装) 处理。
