# Codex Signal 0.8.1 · Build 13

修复检查更新总是失败（HTTP 403）。

## 更新内容

- 检查更新改为读取最新版附带的 `SHA256SUMS.txt`，不再调用 GitHub API。API 对未登录请求按 IP 限额每小时 60 次，经代理、VPN 或公司网络等共用出口时常被他人用完，检查就会一直返回 403。
- 下载后照旧校验 SHA-256、应用标识、版本、最低系统版本和代码签名。

## 下载和升级

需要 macOS 14+ 和 Apple Silicon（M 系列芯片）。`arm64.dmg` 和 `arm64.zip` 任选一个下载，可用随附的 `SHA256SUMS.txt` 校验。

**如果你的检查更新一直显示 403，请手动下载此版本一次**：0.8.0 及更早版本仍通过 GitHub API 检查更新。退出旧版，下载 DMG 后将新版 `CodexSignal.app` 拖入“应用程序”并替换，已有设置和提醒保存在本地数据目录。0.7.0 及更早版本同样需要手动下载。

首次安装见 [安装与接入说明](https://github.com/Cupcc/codex-signal/tree/v0.8.1#安装)，Claude Code 接入见 [接入 Claude Code](https://github.com/Cupcc/codex-signal/tree/v0.8.1#接入-claude-code)。

## 当前边界

- Claude Code 没有中断 Hook。按 Esc 中断或拒绝授权后，状态保持到下一次提问或退出会话。
- 真实终端中的 Claude Code 标签页定位尚待实机记录。
- 此版本使用 ad-hoc 签名，尚未通过 Apple 公证。首次打开若被 macOS 阻止，按 [安装说明](https://github.com/Cupcc/codex-signal/tree/v0.8.1#安装) 处理。
- 自动更新要求应用所在目录可写，下载完成后由用户选择重启安装。
