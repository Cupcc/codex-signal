# Codex Signal 0.6.0 · Build 7

新增自动接入 Codex Hooks，改进并发请求状态和提醒语音控制。

## 更新内容

- 首次安装、重新安装或升级后的首次启动自动检查 Python 3.9+，安装或更新桥接脚本并配置 Codex Signal 的 Hooks；普通启动恢复上次结果，失败或中断时提供重试。
- 在设置中显示接入状态、Hooks 路径和恢复操作。首次 Hooks 授权仍由 Codex 的 Hooks 设置完成，应用会区分“已配置”和“已收到事件”。
- 独立保留交叠的审批与提问请求；迟到或重复的完成事件只解除对应请求，不会重新挂起其他请求；来源识别后保留已有提醒和语音关联。
- 新增提醒音量设置与预览；保留静音、安静时段、锁屏暂停和串行播放。
- 更新标准与迷你版六态伙伴动效、导出资源、消息接入测试和运行验证脚本。

## 下载和升级

需要 macOS 14+。`universal.dmg` 和 `universal.zip` 均包含 Apple Silicon 与 Intel 架构，任选一个下载。下载包可用随附的 `SHA256SUMS.txt` 校验。

0.3.0 及更新版本可在设置或菜单栏右键菜单检查更新，下载完成后点击“重启并更新”。手动升级时，退出旧版，再将新版 `CodexSignal.app` 拖入“应用程序”并替换；已有设置和提醒保存在本地数据目录。

首次安装见 [安装与接入说明](https://github.com/Cupcc/codex-signal/tree/v0.6.0#安装)。首次打开后请在 Codex 的 Hooks 设置中审阅并信任配置。

## 当前边界

- 此版本使用 ad-hoc 签名，尚未通过 Apple 公证。首次打开若被 macOS 阻止，按 [安装说明](https://github.com/Cupcc/codex-signal/tree/v0.6.0#安装) 处理。
- 自动更新要求应用所在目录可写，下载完成后由用户选择重启安装。
- 本机运行验证环境为 Apple Silicon macOS。Intel 实机、所有终端组合及桌面端完整事件覆盖仍待验证。
