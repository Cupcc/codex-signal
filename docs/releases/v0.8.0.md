# Codex Signal 0.8.0 · Build 12

Claude Code 会话换上专属的橙色小螃蟹，Codex 会话保持蓝色伙伴。

## 更新内容

- Claude Code 会话改用原创的橙色小螃蟹。六种状态与蓝色伙伴一一对应：运行中、空闲、待确认、待回答、待查看和运行失败，提供标准和迷你两种尺寸。
- 会话列表和灵动岛提示按来源显示对应角色，提示的辅助功能名称包含来源。
- 折叠区的角色跟随决定当前状态的会话：等待处理或运行中的全部是 Claude Code 时显示螃蟹；与 Codex 混合时保持蓝色伙伴，不来回切换。
- 状态颜色不变。螃蟹的橙色只用于角色本身，待确认仍由琥珀色角标和文字表示。
- 设置、空状态和应用图标仍是蓝色伙伴。

## 下载和升级

需要 macOS 14+ 和 Apple Silicon（M 系列芯片）。`arm64.dmg` 和 `arm64.zip` 任选一个下载，可用随附的 `SHA256SUMS.txt` 校验。

0.7.1 可在应用内自动更新到此版本。0.7.0 及更早版本请手动下载一次：退出旧版，下载 DMG 后将新版 `CodexSignal.app` 拖入“应用程序”并替换，已有设置和提醒保存在本地数据目录。

首次安装见 [安装与接入说明](https://github.com/Cupcc/codex-signal/tree/v0.8.0#安装)，Claude Code 接入见 [接入 Claude Code](https://github.com/Cupcc/codex-signal/tree/v0.8.0#接入-claude-code)。

## 当前边界

- Claude Code 没有中断 Hook。按 Esc 中断或拒绝授权后，状态保持到下一次提问或退出会话。
- 真实终端中的 Claude Code 标签页定位尚待实机记录。
- 此版本使用 ad-hoc 签名，尚未通过 Apple 公证。首次打开若被 macOS 阻止，按 [安装说明](https://github.com/Cupcc/codex-signal/tree/v0.8.0#安装) 处理。
- 自动更新要求应用所在目录可写，下载完成后由用户选择重启安装。
- 所有终端组合及 Codex 桌面端完整事件覆盖仍待验证。
