# Codex Signal 0.7.1 · Build 11

仅支持 Apple Silicon，并修复 Claude Code 中断后退出时状态停留在运行中的问题。

## 更新内容

- 只构建和发布 Apple Silicon（arm64）版本，不再包含 Intel。下载包改名为 `CodexSignal-0.7.1-arm64.dmg` 与同名 ZIP。
- Claude Code 中断一轮后退出会话（如 `/exit`），这一轮会显示为已停止，不再一直显示运行中。
- slash 命令等未经提问 Hook 开始的 Claude Code 轮次，在首个工具或结束事件时显示为运行中。
- 移除 Claude Code 的空闲通知 Hook：实测它只在正常结束后发出，无法收起中断的轮次。升级后的首次启动会移除 0.7.0 写入的对应接收器，`~/.claude/settings.json` 中的其他设置保留，修改前保存备份。

## 下载和升级

需要 macOS 14+ 和 Apple Silicon（M 系列芯片）。`arm64.dmg` 和 `arm64.zip` 任选一个下载，可用随附的 `SHA256SUMS.txt` 校验。

**0.7.0 及更早版本无法自动更新到此版本**，因为下载包已改名。请退出旧版，下载 DMG 后将新版 `CodexSignal.app` 拖入“应用程序”并替换；已有设置和提醒保存在本地数据目录。之后的版本恢复应用内自动更新。

首次安装见 [安装与接入说明](https://github.com/Cupcc/codex-signal/tree/v0.7.1#安装)，Claude Code 接入见 [接入 Claude Code](https://github.com/Cupcc/codex-signal/tree/v0.7.1#接入-claude-code)。

## 当前边界

- Claude Code 没有中断 Hook。按 Esc 中断或拒绝授权后，状态保持到下一次提问或退出会话。
- Claude Code 交互会话的授权、提问和退出已实测；真实终端中的标签页定位尚待实机记录。
- 此版本使用 ad-hoc 签名，尚未通过 Apple 公证。首次打开若被 macOS 阻止，按 [安装说明](https://github.com/Cupcc/codex-signal/tree/v0.7.1#安装) 处理。
- 自动更新要求应用所在目录可写，下载完成后由用户选择重启安装。
- 所有终端组合及 Codex 桌面端完整事件覆盖仍待验证。
