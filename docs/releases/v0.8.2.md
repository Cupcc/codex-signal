# Codex Signal 0.8.2 · Build 14

修复面板已收起、鼠标移入仍转彩球的问题。旧版在会话较多时可能持续布局隐藏的列表，占满一个 CPU 核心，内存占用也可能持续增长。

现在可见会话超过 8 条时，收起面板会卸载滚动列表。后台继续接收会话事件。再次展开时会显示最新状态，并定位到选中的会话。

在 macOS 27 上快速收起面板时，应用也会先关闭刚打开的设置和嵌套帮助浮层。

## 升级

- 0.8.1 仍能响应时，可以在设置中检查更新，下载后选择重启安装。0.7.0 及更早版本请从本页下载 DMG 手动升级。
- 如果已经卡住，可以在“活动监视器”中结束 CodexSignal，下载本页的 DMG，把新版应用拖到“应用程序”并替换。已有会话、设置和待处理事件保存在原数据目录，新版会继续读取。
- 需要 macOS 14 或更高版本及 Apple Silicon 芯片。DMG 和 ZIP 均可用随附的 `SHA256SUMS.txt` 校验。应用使用 ad-hoc 签名，尚未通过 Apple 公证。[安装说明](https://github.com/Cupcc/codex-signal/tree/v0.8.2#安装)

现场采样、回归测试和内存归因的验证范围见[排查记录](https://github.com/Cupcc/codex-signal/blob/v0.8.2/docs/playbooks/2026-11-21-collapsed-session-list-hang.md)。
