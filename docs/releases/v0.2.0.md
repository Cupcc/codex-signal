# Codex Signal 0.2.0 · Build 2

新增灵动岛短暂提醒和终端会话恢复，并修复部分会话结束后仍显示运行中的问题。

## 更新内容

- 审批、提问、本轮结束和异常会短暂展开提示，6 秒后收起。多条提醒合并显示，点击可进入对应会话；等待解除后撤回对应提示。
- 灵动岛提示与语音可分别开关，设置内可预览。收起的伙伴汇总全部会话状态，并显示运行数量。
- 启动时的历史事件、重复事件和子任务完成不会重复弹出提示，查看列表时也不会打断当前选择。
- 返回会话失败时，在 Terminal、iTerm2 或 Ghostty 的新标签页填入恢复命令，等待你按回车继续。无法填入时可手动粘贴已复制的命令。
- 共享服务会话每 5 秒核对一次轮次状态，补回漏收的结束、中断或失败事件。状态修正不播报，也不会重新打开已关闭的提醒。

## 下载和升级

需要 macOS 14+。`universal.dmg` 和 `universal.zip` 均包含 Apple Silicon 与 Intel 架构，任选一个下载。

退出旧版后，打开 DMG，将 `CodexSignal.app` 拖入“应用程序”并替换旧版；也可解压 ZIP 后替换应用。已有设置和提醒保存在本地数据目录。若移动了应用或更换 Python，需要重新生成 Hooks 配置。

首次安装请按 [README 接入 Codex](https://github.com/Cupcc/codex-signal/tree/v0.2.0#接入-codex)。应用包包含事件桥脚本，接入需要 Python 3。

**此版本使用 ad-hoc 签名，尚未通过 Apple 公证。** 首次打开可能被 macOS 阻止，处理步骤见 [安装说明](https://github.com/Cupcc/codex-signal/tree/v0.2.0#安装)。下载包可用随附的 `SHA256SUMS.txt` 校验。

## 当前边界

- 状态核对仅覆盖已确认属于本地 Codex 共享服务的会话。服务不可用、接口不兼容或找不到匹配轮次时，保留原状态。独立 CLI 仍依赖 Hooks。
- Terminal 的命令填入需要自动化与辅助功能权限；其他终端需要相应的自动化权限。恢复命令由你按回车执行。
- 本机运行验证环境为 Apple Silicon macOS。Intel 实机、所有终端组合及桌面端完整事件覆盖仍待验证。
- 关闭提醒不会取消任务，也不会代替回答或审批。
