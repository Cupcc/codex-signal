# Codex Signal 0.6.2 · Build 9

新增开机启动设置，并将退出入口集中到设置。

## 更新内容

- 设置中可开启或关闭开机启动；系统需要授权时显示当前状态。
- 从灵动岛和菜单栏菜单移除重复的退出入口，设置底部保留退出按钮与 ⌘Q。
- 打开待审批或待回答的会话后保留提醒，直到对应请求解决。

## 下载和升级

需要 macOS 14+。`universal.dmg` 和 `universal.zip` 均包含 Apple Silicon 与 Intel 架构，任选一个下载。下载包可用随附的 `SHA256SUMS.txt` 校验。

0.3.0 及更新版本可在设置或菜单栏右键菜单检查更新，下载完成后点击“重启并更新”。手动升级时，退出旧版，再将新版 `CodexSignal.app` 拖入“应用程序”并替换；已有设置和提醒保存在本地数据目录。

首次安装见 [安装与接入说明](https://github.com/Cupcc/codex-signal/tree/v0.6.2#安装)。

## 当前边界

- 此版本使用 ad-hoc 签名，尚未通过 Apple 公证。首次打开若被 macOS 阻止，按 [安装说明](https://github.com/Cupcc/codex-signal/tree/v0.6.2#安装) 处理。
- 自动更新要求应用所在目录可写，下载完成后由用户选择重启安装。
- 本机运行验证环境为 Apple Silicon macOS。Intel 实机、所有终端组合及桌面端完整事件覆盖仍待验证。
