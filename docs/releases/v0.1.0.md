# Codex Signal 0.1.0 · Build 1

首个 GitHub 发布版本。让 Codex 的运行、审批和提问状态留在 macOS 屏幕顶部。

- 原生伙伴岛、多会话列表与键盘操作。
- CLI Hook 接入、会话导航和持久化状态。
- 中文系统语音、安静时段与锁屏暂停。
- 蓝色伙伴五态动效，支持“减少动态效果”。
- 关闭单条提醒，或按 7、15、30 天自动清理。

## 下载和安装

需要 macOS 14+。`universal.dmg` 和 `universal.zip` 均包含 Apple Silicon 与 Intel 架构，任选一个下载。Apple Silicon 已完成本地运行验证；Intel 尚未经过实机验证。

打开 DMG，将 `CodexSignal.app` 拖到“应用程序”；或解压 ZIP 后移动应用。安装后按 [README](https://github.com/Cupcc/codex-signal#接入-codex) 生成 Hooks 配置，并在 Codex 官方界面完成信任审阅。应用包包含事件桥脚本，接入需要 Python 3。

**此版本使用 ad-hoc 签名，尚未通过 Apple 公证。** 首次打开可能被 macOS 阻止，请查看 README 中的安装说明。下载包可用随附的 `SHA256SUMS.txt` 校验。

## 当前边界

- CLI 的开始、结束、审批、提问、中断及等待解除已有本地真实接入记录；桌面端完整覆盖仍待验证。
