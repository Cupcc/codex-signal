# Codex Signal 0.5.0 · Build 6

新增蓝色伙伴应用图标和产品信息，修复设置失焦后折叠跳位。

## 更新内容

- Finder 和“关于”窗口使用蓝色伙伴应用图标，补齐应用类别、语言和版权信息。
- “关于”显示产品简介、项目主页、问题反馈与第三方许可入口。设置中显示应用图标、版本和构建号，并提供“关于”按钮。
- 展开面板右下角增加“退出”按钮，支持 ⌘Q。
- 设置失焦或按 Escape 时，等待设置浮层完成关闭后再折叠主面板，避免关闭过程中的跳位。

## 下载和升级

需要 macOS 14+。`universal.dmg` 和 `universal.zip` 均包含 Apple Silicon 与 Intel 架构，任选一个下载。下载包可用随附的 `SHA256SUMS.txt` 校验。

0.3.0 及更新版本可在设置或菜单栏右键菜单检查更新，下载完成后点击“重启并更新”。手动升级时，退出旧版，再将新版 `CodexSignal.app` 拖入“应用程序”并替换；已有设置和提醒保存在本地数据目录。

首次安装见 [安装与接入说明](https://github.com/Cupcc/codex-signal/tree/v0.5.0#安装)。事件接入需要 Python 3；应用包包含桥接脚本。移动应用或更换 Python 后，需要重新生成 Hooks 配置。

## 当前边界

- 此版本使用 ad-hoc 签名，尚未通过 Apple 公证。首次打开若被 macOS 阻止，按 [安装说明](https://github.com/Cupcc/codex-signal/tree/v0.5.0#安装) 处理。
- 自动更新要求应用所在目录可写，下载完成后由用户选择重启安装。
- 本机运行验证环境为 Apple Silicon macOS。Intel 实机、所有终端组合及桌面端完整事件覆盖仍待验证。
