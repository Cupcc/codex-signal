# Codex Signal 0.7.0 · Build 10

新增 Claude Code 支持：在同一个灵动岛中查看 Codex 与 Claude Code 会话。

## 更新内容

- 升级后的首次启动检测 Claude Code，并将 Hooks 合并进 `~/.claude/settings.json`（或 `CLAUDE_CONFIG_DIR`），保留其他设置，修改前保存备份。未安装 Claude Code 时不创建配置目录，可在设置中一键配置。Claude Code 自动载入 Hooks，无需审阅。
- 显示 Claude Code 会话的运行、待确认、待回答、本轮结束和运行失败；授权与提问按工具调用关联。Claude Code 报告输入空闲或会话结束时，收起未结束的轮次。
- 打开 Claude Code 会话时回到原终端标签页，找不到时在新标签页填入 `claude --resume` 命令。
- 设置中分别显示 Codex 与 Claude Code 的接入状态。列表来源改为“Codex CLI”“Codex 桌面版”“Claude Code”。
- Claude Code 提醒使用独立的中文语音。

## 下载和升级

需要 macOS 14+。`universal.dmg` 和 `universal.zip` 均包含 Apple Silicon 与 Intel 架构，任选一个下载。下载包可用随附的 `SHA256SUMS.txt` 校验。

0.3.0 及更新版本可在设置或菜单栏右键菜单检查更新，下载完成后点击“重启并更新”。手动升级时，退出旧版，再将新版 `CodexSignal.app` 拖入“应用程序”并替换；已有设置和提醒保存在本地数据目录。

首次安装见 [安装与接入说明](https://github.com/Cupcc/codex-signal/tree/v0.7.0#安装)，Claude Code 接入见 [接入 Claude Code](https://github.com/Cupcc/codex-signal/tree/v0.7.0#接入-claude-code)。

## 当前边界

- Claude Code 没有中断 Hook。按 Esc 中断或拒绝授权后，状态保持到 Claude Code 报告输入空闲（约 60 秒）、会话结束或下一次提问。
- Claude Code 的非交互运行已实测；交互会话中的授权、提问、空闲通知与标签页定位尚待实机记录。
- 此版本使用 ad-hoc 签名，尚未通过 Apple 公证。首次打开若被 macOS 阻止，按 [安装说明](https://github.com/Cupcc/codex-signal/tree/v0.7.0#安装) 处理。
- 自动更新要求应用所在目录可写，下载完成后由用户选择重启安装。
- 本机运行验证环境为 Apple Silicon macOS。Intel 实机、所有终端组合及 Codex 桌面端完整事件覆盖仍待验证。
