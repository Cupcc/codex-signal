# Codex Signal 0.4.0 · Build 4

新增“全部已读”和内置中文语音提醒，展开高度适配列表内容，并修复窗口偏离顶部中心的问题。

## 更新内容

- 点击“全部已读”清除已结束及异常提醒。该操作覆盖全部筛选，保留运行中、待确认和待回答会话。保存失败时保留原状态，可重试。
- 展开面板按实际内容调整高度，长列表保留滚动；连续展开收起、动画中断或窗口移位后恢复顶部居中。
- 审批、提问、失败、结束及多会话合并提醒使用六段内置中文音频，按顺序播放。保留静音、勿扰时段与锁屏暂停，重新开启不补播。
- 调整设置布局，集中展示终端、提醒、勿扰时段、自动清理与快捷键；更新状态和下载入口更紧凑。

## 下载和升级

需要 macOS 14+。`universal.dmg` 和 `universal.zip` 均包含 Apple Silicon 与 Intel 架构，任选一个下载。下载包可用随附的 `SHA256SUMS.txt` 校验。

0.3.0 用户可在设置或菜单栏右键菜单检查更新，下载完成后点击“重启并更新”。手动升级时，退出旧版，再将新版 `CodexSignal.app` 拖入“应用程序”并替换；已有设置和提醒保存在本地数据目录。

首次安装见 [安装与接入说明](https://github.com/Cupcc/codex-signal/tree/v0.4.0#安装)。事件接入需要 Python 3；应用包包含桥接脚本。移动应用或更换 Python 后，需要重新生成 Hooks 配置。

## 当前边界

- 此版本使用 ad-hoc 签名，尚未通过 Apple 公证。首次打开若被 macOS 阻止，按 [安装说明](https://github.com/Cupcc/codex-signal/tree/v0.4.0#安装) 处理。
- 自动更新要求应用所在目录可写，下载完成后由用户选择重启安装。
- 本机运行验证环境为 Apple Silicon macOS。Intel 实机、所有终端组合及桌面端完整事件覆盖仍待验证。
- “全部已读”和关闭提醒不会取消任务，也不会代替回答或审批。
