# 蓝色伙伴动效

已沿用现有形象与 B「会话伙伴岛」结构，为五态补充浏览器内可运行的角色动效。打开 [角色预览](ui/08-character.html) 可切换状态、重播、暂停和开启减少动态效果；已有 UI 源页面同步使用同一动画实现。

原生应用现已接入同一套五态节奏，见文末「原生应用接入」。下文原有浏览器验证记录保留其历史范围。

| 状态 | 动作 | 播放规则 |
|---|---|---|
| 休息 | 缓慢起伏、身体呼吸，短暂睁眼再闭上 | 呼吸3.2秒；睁眼6.4秒一轮，约3秒睁开、3.84秒前闭合 |
| 工作 | 整只起伏、双鳍交替摆动，间歇眨眼 | 1.8秒一轮，末段留停顿；右鳍晚120ms；眨眼周期4.6秒 |
| 等待审批 | 先蓄力再弹起，右鳍挥动两次，角标回弹 | 最长1.1秒，只播放一次 |
| 有个问题 | 整只歪头并停顿，再回正，右鳍抬起 | 最长1.2秒，只播放一次 |
| 运行中断 | 左右短促摇头、幅度逐渐衰减，角标回弹 | 最长800ms，只播放一次 |

幅度以128×128设计坐标计：工作整体纵向范围−8至+1单位、双鳍最大22度；休息起伏4单位、身体纵向呼吸4.5%；审批最高弹起10单位；提问歪头12度；异常横向最大±7单位。按原生22/32px的小尺寸优先调节，使工作起伏仍有约1.5/2.25px可见位移，身体与双鳍保持整体性。大角色与小尺寸共用节奏。状态文本立即切换，不等待动画播放。

## 暂停与辅助功能

- 暂停按钮冻结当前帧，继续时接着播放；显式重播则从动作起点开始。
- 页面进入后台或角色离开可视区域时暂停；回到前台/可视区域后继续。已完成的一次性动作不会因此重播。
- 系统 `prefers-reduced-motion` 或页面复选框开启时，取消角色动画并显示完整静止姿态。系统设置优先，页面不能强行恢复系统禁用的动画。
- 减少动态效果下仍可切换状态，重播和暂停按钮禁用。
- SVG保留可访问名称，状态按钮可键盘操作，有明确焦点与选中状态。

## 文件

- `assets/build_toys.py`：生成10份静态SVG及离线绘图数据 `mascot-art.js`。
- `assets/mascot-motion.js`：以Web Animations API增强静态图片，管理一次性/循环播放、后台与离屏暂停；每只角色的SVG渐变ID独立。
- `assets/mascot-preview.js`：角色页的状态切换和播放控件。

源HTML直接用浏览器打开即可运行，无网络、构建工具或新增依赖。JavaScript不可用时保留原静态图片。离线三版对比页和PNG仍用于静态画面对照；角色动效以HTML源页面为准。

- 系统减少动态效果模拟：全部角色动画取消，重播禁用。真实浏览器切到新标签页后记录到后台暂停，切回后恢复。
- 定格检查了审批、工作、休息动画时间点；休息7100ms时睁眼透明度1、闭眼透明度0。

## 原生应用接入（2026-11-09）

- 原因：原生 `MascotView` 只读取整张静态 PNG；HTML 的 Web Animations 没有参与应用渲染。
- `scripts/render_mascot_layers.py` 从同一份 `build_toys.py` 绘图提取身体、眼睛、双鳍、角标与阴影，共62张透明 PNG（约644KB）。`render-assets.sh` 同时更新这些图层。
- `MascotAnimation.swift` 记录原设计的五态关键帧；`AnimatedMascot.swift` 通过小型 AppKit 桥接取得窗口生命周期，用 Core Animation 播放，不依赖网页或逐帧重绘会话列表。支持22px迷你角色及32/48/56px标准角色。
- 工作和休息循环播放；审批、提问、异常播放一次后保持最终姿态。普通数据更新与收起／展开不会重播一次性提醒。隐藏的展开列表、隐藏的浮条、消失的视图、不可见窗口及屏幕睡眠会暂停，恢复后继续。
- 系统减少动态效果开启时取消动画并保持静态姿态；重新开启动态效果只恢复循环，不重播已出现的审批或问题。
- SwiftUI 托管视图可能在实际可见时返回空的 AppKit `visibleRect`，因此播放条件使用 SwiftUI 生命周期、展开状态及窗口可见性；已加入该情况的回归测试。
- 原生窗口连续截图验证：工作角色70张截图中检测到37个不同图像，确认动画实际推进；收起时列表图层时钟冻结，浮条时钟恢复。证据保存在 `.audit/motion-native/`。此检查不等同于性能或帧率测试。

## 动效可见度优化（2026-11-09）

- 原因：原工作身体仅移动1.4单位，在22/32px下只有约0.24/0.35px；审批、问题和异常的动作也过短。
- 保留蓝色伙伴和现有五态，只加强轮廓位移、鳍摆幅与动作停顿；原生和HTML同步更新。提醒仍只播放一次，后台暂停和减少动态效果规则不变。
- 原生动效专项5项测试通过：素材、播放与暂停时钟、状态替换、减少动态效果、一次性动作收束。使用项目 `script/test.sh` 的 Testing framework 搜索路径运行筛选测试。
- 浏览器13项检查通过，覆盖起伏关键帧、暂停与恢复、三种提醒仅播一次及收束、减少动态效果、恢复不重播和快速切换。
- 使用原生图层和实际轨道重新导出 `exports/mascot-motion/` 的五态GIF；查看 `.oil-ui/motion-stronger/shots/native-sequence.png` 中的序列与22/32px尺寸，以及浏览器实际页面。此次为局部动效参数修改，由主Agent自检，未派独立评审；没有测量帧率或CPU。

## 折叠状态与灵动岛提示（2026-11-10）

目标：工作时能一眼确认任务仍在运行；需要交接时，伙伴和小岛一起提醒。沿用 B「会话伙伴岛」和原创蓝色角色。

- **折叠状态**：按全部可见会话汇总，与列表筛选无关。待确认／待回答优先，其次运行中、异常，最后才休息。左侧数字为运行数，右侧为待处理数；没有待处理时显示未查看数。旧的结束记录不能盖住运行中的会话。
- **结构**：`[伙伴 运行数] [硬件刘海] [待处理／未查看数]`；提醒时从这一条向下展开，增加 `[角色] [状态 + 项目／标题] [查看] [收起]`。不直接弹出完整列表。
- **三个动作**：新事件到达，小岛顶部保持固定，向下展开约 300ms；对应伙伴招手、歪头或摇头，状态边缘染色；停留 6 秒后以约 200ms 收回。点击查看沿原位置展开列表并选中对应会话。
- **状态**：审批用橙色，问题用蓝色，失败用红色；结束文案仅称「本轮已结束」。工作循环继续沿用现有双鳍动作，不靠提示是否显示决定工作姿态。
- **打断与合并**：短时间到达的提醒合并到同一张提示，人工介入优先于失败和结束。开始／恢复、已查看、关闭提醒后撤下过期提示；收起提示本身不标记已查看，也不代替处理。列表已展开时保留当前阅读位置，不另弹提示。
- **声音**：保留 3 秒聚合中文播报；多个任务结束时说「有多个任务本轮已结束」。语音与视觉提示独立开关，静音及勿扰时段仍可显示小岛。设置中的「预览提醒」展示一次短提示，并按当前语音设置播放。
- **设备与辅助功能**：提示内容位于刘海下方，无刘海屏幕使用同一悬浮表面。后台事件不获取键盘焦点；减少动态效果时直接显示完整状态，无需等待动画。锁屏不新增提示，启动时不补播历史提醒。

验证重点：旧结束记录 + 新运行会话、筛选不影响状态、重复事件与同批解除、子任务结束抑制、多提醒优先级、自动收起保留待处理标记、提示点击定位、语音关闭时仍有视觉提示。

本轮验证：项目 `script/test.sh` 通过（106 项 Swift、43 项 Python）；打包应用 `verify_runtime.py --check-speech` 通过启动积压、静音视觉提醒、请求解除、重复事件、元数据刷新与重启检查。CUA 查看真实运行应用的工作姿态，并在隔离数据目录验证审批短提示与点击选中对应会话；设置预览可见并自动收回。局部组件由主 Agent 实际看图与操作自检，未派独立评审。测试记录位于本地 `.audit/island-notifications/`；未测量帧率，未在本轮切换系统锁屏或减少动态效果设置。


## 待查看（2026-11-10）

新增第六态 `ready`：睁眼、双鳍托住淡紫色结果卡，右上角保留文档徽标。进入时轻抬一次（900ms），随后静止；减少动态效果时直接显示完整姿态。休息态只用于空闲或已查看，不能再代表未查看的完成结果。原生与网页共用素材生成器；现在共12份SVG和74张原生图层。

展示规则：`completed && !seen && !dismissed` 为“待查看”。完成提示六秒后收起，但结果标记继续保留，重启不丢失。选择、展开或跳转不会自动确认已查看；显式“标记已查看”将完成结果移出列表。关闭提醒、新一轮开始及现有提醒保留期限仍按原规则处理。

列表提供“全部 / 待处理 / 待查看”筛选。“待处理”仍只包含审批与提问，即使已查看也继续保留；“待查看”仅包含完成结果。失败和停止保持独立语义。收起区可同时显示橙色待处理计数与紫色结果计数；有会话运行时角色继续工作，无会话时使用独立空闲呈现。

验证：108项Swift测试、43项Python测试通过，打包签名通过。新增回归覆盖提示消失、重启、已查看持久化、新回合、筛选、失败与停止排除，以及新素材在标准/迷你尺寸和减少动态效果下的加载。原生窗口实际检查了三种状态并列、收起双计数、待查看筛选和点击已查看后的空状态；该窗口使用隔离测试数据。
