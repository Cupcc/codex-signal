# 参考拆解与设计决定

用户已明确指定 **wxtsky/CodeIsland 为设计基础**，并喜欢 icon toy 状态角色。本轮沿用前一轮技术调研，检查公开截图和 DexView.swift；保留 CodeIsland 产品框架；用户进一步选择 Coucou 式圆润小玩偶，正式稿据此采用原创圆润角色，Coucou 是角色气质参考。

## 产品参考：CodeIsland

实际查看了官方仓库的 `docs/images/readme-approval.png` 和 `readme-hero.png`；截图用于内部比较，不作为正式 UI 资产。

可观察到的要素：

1. 贴合屏幕顶部的黑色区域，把硬件刘海与内容表面连成一体。
2. 项目与分支位于顶部，先交代动作属于哪个工作对象。
3. 权限标签与请求标题并列，文字直接解释需要注意的原因。
4. 命令有独立的深色阅读区，等宽字体区分可执行内容和解释。
5. 操作区右对齐，允许与拒绝用明显颜色区分。
6. 静音、设置和电源图标排在顶部边缘，与当前请求分层。
7. 底层桌面被黑色高对比卡片压低，卡片成为注意力焦点。

保留：黑色刘海面板、状态小角色、事件标签、项目与来源、会话条目、全局语音入口。变化：默认聚焦需要介入的对象，优化中文排版，加入系统语音，并比较单对象/原生列表/固定项目三种组织方式。提醒优先模式以「查看会话」为主动作；原项目已有审批能力是否启用，作为后续偏好选项决定。

来源：[项目仓库](https://github.com/wxtsky/CodeIsland)、[审批截图](https://raw.githubusercontent.com/wxtsky/CodeIsland/main/docs/images/readme-approval.png)。

## 产品参考：Coucou

实际查看了官方仓库 `docs/media/claude-code.png`。

可观察到的要素：

1. 角色与项目名占据左列，代码内容占据右侧大区域。
2. 黑色外壳、深灰内容面、接近黑色的代码底形成三层。
3. Read/Edit/Bash/Done 列表让状态有明确的纵向位置。
4. 角色面部承担情绪识别，与工作状态相互呼应。
5. diff 的红绿行直接呈现正在修改的内容，视觉重心是实际产物。
6. 顶部的 home、聊天、新建、设置、声音暗示较宽的应用范围。

保留：圆润小玩偶的柔和材质、简短面部表情，以及角色与状态相互呼应的思路。改变：围绕 CodeIsland 的会话框架原创绘制带手脚与叶片胸标的小玩偶，不移植 Coucou 的聊天、diff、邮件或独立语音助手功能。

来源：[项目仓库](https://github.com/Louis-CFM/coucou)、[会话截图](https://raw.githubusercontent.com/Louis-CFM/coucou/main/docs/media/claude-code.png)。

## 交互参考与证据边界

CodeIsland 的 README、事件策略源码和提问测试说明了审批、提问、完成的不同路由，以及合并提醒、前台抑制和后续提醒。这些是实现层参考，未在本机安装该 App 逐项操作验证。

参考路径：事件进入 → 排队/选中对象 → 显示对应卡片 → 用户查看或处理 → 请求解除。Signal 采用相同的事件语义，但首版把真正的审批和回答留在 Codex 原有界面。

静态截图不能证明点击是否能准确定位会话，仓库里存在测试也不等于本轮已运行测试。因此会话跳转、声音手感、状态恢复与原生窗口行为标为后续工程验收项。

## 技术事实与产品建议的区分

官方可核查事实：Codex 支持 Stop、PermissionRequest 等生命周期 Hooks；Hook 需要审核信任；notify 有独立配置入口。

本项目设计建议：提醒优先级、6 秒展示、3 秒聚合、60 秒后一次提醒、状态文案、三种 UI 信息结构。这些属于待验证的产品选择。

正式稿使用 HTML/CSS 与原创代码绘制的圆润玩偶 SVG，没有使用 AI 生图，也没有把第三方截图嵌入界面。早期准备的 CodeIsland Dex 静态 SVG 作为可选经典皮肤素材保留，其 MIT 许可与署名位于 assets/。默认圆润皮肤与经典皮肤的来源分别见 [素材说明](assets/ATTRIBUTION.md)。
