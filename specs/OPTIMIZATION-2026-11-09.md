# 会话标题、定位与界面优化

本轮继续既定纵向会话岛，对比本地 CodeIsland `03c77e9` 与 Coucou `b1bc09d` 源码后完成增量实现。没有引入上游审批、远程控制或角色资产。

## 对比与实现

| 范围 | 上游启发与本 app 的变化 |
| --- | --- |
| 标题 | CodeIsland SessionTitleStore 使用 thread_name 索引；本 app 同样按精确会话ID读取最新标题，并在 Hook 中支持只读数据库回退。标题为第一层，两行显示；项目和来源为辅助信息 |
| 导航 | CodeIsland TerminalActivator 使用线程深链接及TTY定位；Coucou仅打开来源app。本 app 按UUID请求打开会话，Terminal/iTerm按TTY选择；不按目录或窗口名猜测。其余CLI复制安全引用的恢复命令 |
| 窗口 | 保留非激活NSPanel和真实刘海测量；hosting root不再随展开重建。新增贴边肩角、圆润底边、细描边、像素对齐；窗口按行数和屏幕可用区域决定大小 |
| 动效 | 展开0.30秒、收起0.20秒，内容固定目标宽度避免动画途中反复换行；选中详情、筛选底板、悬停和按钮反馈。遵循减少动态效果设置 |
| 逻辑 | 批量事件一次持久化后清理收件；失败回滚并重试。标题更新不改变等待时间/已读或发声。查看完成项后选择留在相邻位置；查看审批不解除待处理；禁止重复导航 |

详细来源：[元数据](research/session-metadata.md)、[会话导航](research/session-navigation.md)。许可见 ThirdParty。

## 验证

- 50项 Swift、37项 Python 测试和打包构建通过。
- 隔离运行验收8项通过：242条逆文件名事件积压、启动静音、请求匹配与旧回合保护、事件去重、仅元数据更新、重启恢复、重启静音、单写者锁。
- 实际原生窗口检查：三条会话及选中操作完整显示，长中文标题两行可读；待处理筛选和设置浮层可用；标记已查看后审批仍保留。
- 用当前真实线程UUID在隔离数据目录注入状态，真实标题由本地index加载；点击后系统接受指定线程链接，界面显示“已请求 Codex 打开此会话”。CUA禁止读取目标Codex app，因此没有目视确认目标会话渲染，不把URL交付当作完整端到端导航成功。
- 独立视觉评审未见裁切/可读性阻断，已修状态颜色、动作图标、重复恢复入口与键盘提示不一致。

## 边界

Terminal/iTerm实际标签切换与首次自动化权限未实测。TTY可能被系统复用，尚无PID+启动时间联合校验。后续已补Ghostty 1.4+ TTY定位；缺少TTY的Ghostty会话、tmux/远程主机仍只提供恢复命令，详见导航增量核查。没有改动用户的自动化权限。

本机实际检查为刘海屏；外接屏、小屏和负坐标布局经过几何测试，未做所有硬件组合的实机验证。没有声称测得帧率或完成所有动态中间帧验收。

默认读取 CODEX_HOME 或 ~/.codex；未自动扫描其他账户。标题索引读取尾部最多8MiB。缺少index记录的旧会话需要下次Hook补数据库标题。完整历史列表、搜索、跨来源身份合并、其他终端适配仍可继续迭代。
